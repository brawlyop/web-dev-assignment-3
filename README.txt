LAB 3 - PORTFOLIO WEBSITE (INTERNAL CSS VERSION)

This version uses INTERNAL CSS in a <style> section inside the <head> of each HTML file.
There is NO external CSS file and no link rel="stylesheet".

Files:
- index.html
- about.html
- skills.html
- projects.html
- contact.html

HOW TO RUN:
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html in your browser or use Live Server.
4. Use the navigation bar to move between pages.

The profile visual uses TY initials instead of a personal photo.
The project cards include sample/practice project ideas; replace them with actual work when available.

CSS features used: Flexbox, Grid, media queries, flexible units, hover effects,
transitions, keyframe text animation, sticky navigation.
